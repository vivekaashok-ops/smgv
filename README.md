The Repository SMGV, or Social Media and Gun Violence, refers to the study: "Firearm Violence and Health in Policymaker Discourse: A Mixed-Methods Social Media Analysis"
Preprint in JMIR Formative Research: https://preprints.jmir.org/preprint/80397

Files included, descriptions, and how to use:
1. smgv_rawcdata_codes.csv - This file contains anonymized X posts from Pennsylvania state legislators from 2017-2022. The data set includes a unique identifier, the X post content, and the qualitative codes mapped deductively mapped onto the post by our coding team.
2. smgv_datadictionary.csv - This file contains the data dictionary for our analytic codes used for qualitative content analysis of X posts from 2017-2022.
3. MA_Codebook.doc - This file contains the codebook used for content analysis of X posts.
